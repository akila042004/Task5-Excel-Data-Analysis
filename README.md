Excel Data Analysis – Task 5

Project Overview

This project focuses on analyzing retail sales data to identify trends, evaluate performance, and generate meaningful business insights.

Objectives

- Perform data cleaning and preprocessing.
- Sort and filter records.
- Calculate key performance indicators (KPIs).
- Analyze sales by category, region, product, and month.
- Visualize data using charts.
- Generate insights to support business decisions.

Tools & Technologies

- Python
- Pandas
- Matplotlib
- Google Colab
- Excel

Analysis Performed

- Missing value and duplicate checking
- Sales and profit calculations
- Category-wise analysis
- Region-wise analysis
- Product performance analysis
- Monthly sales analysis
- Data visualization

Output

An Excel workbook containing raw data and separate analysis sheets for categories, regions, products, and monthly sales.

Conclusion

The project demonstrates how data analysis techniques can transform raw sales data into useful information for understanding business performance and supporting decision-making.
